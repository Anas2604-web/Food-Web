> 🚀 **Delicious Bites** is a modern, dynamic, and responsive **food delivery frontend** built with **React.js + Tailwind CSS**.  
> It integrates with the **Swiggy live API** to display real-time restaurant and food data.  
> Reliability is ensured through **unit testing and intergration testing with Vitest & React Testing Library (RTL)**.

## ✨ Features  

- 🍔 **Real-time Data** – Fetches restaurants & menus using Swiggy API  
- 🎨 **Responsive UI/UX** – Optimized for mobile, tablet & desktop  
- ⚡ **Fast & Modern** – Built with Vite + React + Tailwind CSS  
- 🧪 **Tested Components** – Unit testing and Intergration testing with **Vitest** & **RTL**  
- 🚀 **Deployed on Vercel** – Smooth Workflow

---

## 🛠️ Tech Stack  

**Core:**  
- ⚛️ React.js (with Hooks)  
- 🎨 Tailwind CSS (utility-first styling)  
- ⚡ Vite (fast dev & build)  

**Testing:**
